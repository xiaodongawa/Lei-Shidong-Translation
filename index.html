关于
来源
2012 年，Minecraft Java 版 1.3 上线前，官方把游戏文本放到 Crowdin 让玩家社区协作翻译。 一位自称「精通多门语言」的用户提交了大批机翻：Redstone 音译成「雷石东」， Repeater 用通信行业的说法译成「直放站」，红石中继器于是变成「雷石东直放站」。 当时没有审核机制，这批译名就这么进了正式版。
